# FAQ technique et sécurité (FICTIVE)

- **Hébergement** : 100 % France, OVHcloud (Roubaix + Gravelines, réplication), aucune donnée hors UE.
- **Certifications** : ISO 27001 (depuis 2023), rapport SOC 2 Type II disponible sous NDA, pentest annuel par un cabinet PASSI.
- **RGPD** : DPA standard fourni, DPO joignable, durée de conservation paramétrable, justificatifs à valeur probante (archivage électronique conforme NF Z42-013).
- **SSO / sécurité d'accès** : SAML 2.0, Microsoft Entra ID, Google Workspace, MFA obligatoire pour les administrateurs.
- **Disponibilité** : SLA 99,9 % (formule Entreprise), 99,5 % (autres). Disponibilité réelle 2025 : 99,97 %.
- **Intégration comptable** : connecteurs natifs (voir Offre). Pour un ERP non listé : export paramétrable (CSV, FEC) ou API REST, délai moyen 10 jours ouvrés.
- **Mobile** : applications iOS et Android, mode hors ligne pour la saisie des tickets.
- **Réversibilité** : export complet des données et justificatifs à tout moment, sans frais.
- **Facture électronique 2026-2027** : Orbis Pilot est connecté à une Plateforme Agréée (PA) partenaire pour la réception des factures fournisseurs.
